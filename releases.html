Release archive

Every WinPython release since 2020. Older builds stay downloadable, but only the current release is maintained. Checksums for every file ever published are in md5_sha1.txt.

Naming changed over the years. Since 2026-03 there are only four suffixes: dot (bare Python), slim (full environment), and dotf / slimf for the free-threaded interpreter — see which build should I take? Earlier releases also used whl (offline wheelhouse), free (renamed to dotf), cod (with VS Code) and 32-bit builds.
